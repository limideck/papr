标签系统设计：面向经济、金融、国家安全、地缘政治的 RSS 自动打标系统核心目标是：多标签、层次化、可扩展、高一致性、可解释，让 AI 稳定地给每篇内容打出结构化标签，便于后续检索、聚合、推荐、趋势分析。1. 标签体系总体架构（推荐采用「四层 + 自由扩展」）

| 层级  | 名称                      | 说明               | 示例                         |
| --- | ----------------------- | ---------------- | -------------------------- |
| L1  | 主领域 (Domain)            | 强制 1~3 个         | 经济、金融、国家安全、地缘政治            |
| L2  | 细分主题 (Topic)            | 每个主领域下预定义子类      | 货币政策、贸易摩擦、供应链、制裁、军事冲突风险 等  |
| L3  | 实体/区域 (Entity & Region) | 国家、组织、公司、人物、关键资产 | 中国、美国、美联储、台海、BRICS、原油、美元 等 |
| L4  | 属性标签 (Attribute)        | 跨领域通用属性          | 风险等级、情绪、时效性、影响力、政策类型 等     |
| L5  | 自由标签 (Free Tags)        | AI 生成的补充关键词（受控）  | 可设置白名单或后处理过滤               |
|     |                         |                  |                            |

推荐主领域划分（可微调）：

- 经济：宏观经济、微观经济、贸易、产业政策、就业、通胀、增长、债务等
- 金融：货币政策、财政政策、资本市场、银行/保险、加密货币、支付清算、系统性风险等
- 国家安全：情报、关键基础设施、科技安全、供应链安全、网络安全、能源安全、粮食安全、军事相关等
- 地缘政治：大国竞争、区域冲突、联盟/国际组织、制裁与反制、外交、战略资源争夺等

跨领域属性标签示例：

- 风险等级：高/中/低
- 情绪：正面/中性/负面/警惕
- 时效性：突发/短期/中长期/结构性
- 影响力：全球/区域/双边/国内
- 政策类型：监管、制裁、刺激、限制、合作

2. 标签规则设计原则

3. 多标签强制：一篇文章通常覆盖 2~5 个标签，不允许只打一个笼统标签。
4. 层次约束：打 L2 时必须对应正确的 L1；实体标签尽量标准化（使用规范名称）。
5. 置信度：每个标签都带置信度（0-1），低于阈值的标记为“待人工确认”。
6. 可解释：要求 AI 输出简短理由或关键句子摘录。
7. 可控自由标签：自由标签数量限制（如最多 3 个），并过滤掉过于宽泛或重复的词。

8. AI 自动打标流程（推荐方案）输入：标题 + 摘要 + 正文前 N 字（或全文，视长度） + 来源 + 发布时间。处理流水线：

9. 预处理：清洗 HTML、提取关键实体（可用 NER 工具辅助）。
10. 主分类：先判断属于哪些 L1 主领域（多标签分类）。
11. 细粒度打标：在对应主领域下选择 L2 主题 + L3 实体/区域 + L4 属性。
12. 自由标签生成：补充具体关键词。
13. 后处理：去重、标准化（同义词映射）、置信度过滤、冲突检测。
14. 输出结构化结果（JSON）。

4. 模型与 Prompt 建议

- 首选：能力较强的 LLM（如 GPT-4o、Claude 3.5/4、Gemini 1.5/2.0、国内的 DeepSeek、Qwen、GLM 等），支持长上下文和结构化输出。
- 成本优化：轻量模型做初筛 + 强模型做精标；或使用微调后的中文分类模型 + LLM 补充。
- Prompt 核心要求：
    - 明确标签体系（把完整 taxonomy 放进 system prompt）。
    - 强制 JSON 输出。
    - 要求“只使用给定标签列表，不得自行发明主标签”。
    - 给出 2~3 个 few-shot 示例。
    - 要求输出置信度和简短理由。

5. 工程实现建议

- 存储：文章元数据 + 标签表（多对多） + 标签置信度与版本。
- 标准化词典：维护国家/组织/公司同义词映射（如“FED”→“美联储”）。
- 反馈闭环：支持人工修改标签 → 收集高质量数据 → 定期微调或优化 Prompt。
- 监控指标：标签覆盖率、人工修正率、标签分布平衡度、新出现高频自由标签。
- 扩展性：当新主题出现时，先进入自由标签，积累一定量后提升为正式 L2 主题。

6. 进阶优化方向

- 加入时间维度标签（历史背景、当前事件、未来展望）。
- 关系标签（例如“A 制裁 B”、“X 与 Y 竞争”）。
- 结合知识图谱，让实体标签可链接到外部知识库。
- 多模型投票或置信度加权，提高稳定性。
- 针对不同来源（官方媒体、智库、商业媒体）设置不同权重或偏见检测。
