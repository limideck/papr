# 搜索、词云与标签：使用指南

面向 Papr 读者与管理员：如何在侧边栏搜索文章、用词云发现热点、用兴趣 / AI 标签整理专题，以及怎样把中英别名配好、搜得更准。

更细的技术说明（运算符完整契约、同义词展开设计）见仓库文档 `docs/search.md`、`docs/search-synonyms.md`。

---

## 1. 侧边栏搜索

侧边栏顶部有搜索框（「搜索文章」）。**输入后按 Enter 才会生效**——边打字不会立刻过滤列表。

搜索生效后，文章列表标题旁会出现 **chips（搜索碎片）**。每个 chip 对应一个条件组：

- 点 chip 上的 ×：**清除该条件**（同一实体的多个写法会一并清掉）
- 清空全部搜索：删掉搜索框内容再 Enter，或清掉所有 chip

### 默认是 AND（多词同时出现）

空格连接的多个词表示 **全部都要匹配**（严格模式），结果会越搜越窄：

| 输入 | 含义 |
| --- | --- |
| `Trump china` | 同一篇文章里既要有 Trump 相关，又要有 china 相关 |

### 常用运算符

与仓库 `docs/search.md` 中的搜索语法一致（大小写不敏感）：

| 写法 | 含义 | 例子 |
| --- | --- | --- |
| `a b` | AND（默认） | `Trump china` |
| `a OR b` | 任一即可 | `Trump OR Biden` |
| `a -b` 或 `a NOT b` | 排除 | `Trump -tariff` |
| `"a b"` | 精确短语（相邻词） | `"interest rate"` |
| `( … )` | 分组 | `(Trump OR Biden) china` |
| `title:a` / `body:a` / `feed:Name` | 限定栏位 | `title:Trump`、`feed:Reuters` |

侧边栏搜索框旁的 **?** 有简要提示；更完整的运算符说明见仓库 `docs/search.md`。

### 同义词展开（词云实体）

若某个词在 **词云实体词典**里（规范名或任一别名），搜索会自动扩成该实体的 **整组别名**：

- **组内**：各写法用 **OR**（英文写 Trump，也能命中只写「特朗普」的文章）
- **组间**：仍按模式连接——UI 列表搜索是 **AND**

因此：

| 输入 | 实际含义（示意） |
| --- | --- |
| `Trump` | Trump **或** 特朗普 **或** 该实体其它别名 |
| `Trump 特朗普` | 同一实体 → **合并成一组 OR**，不会要求一文里同时出现两种写法 |
| `Trump china` | 两个不同概念 → **组与组之间 AND** |
| `AI` / `人工智能`（若已配成同一实体） | 搜任一写法都能互相命中 |

**注意：**

- 兴趣标签的「别名」（自动打标用）**不会**参与全文搜索扩词。
- 引号短语 `"…"` 与 `feed:` 的值 **不**做同义词展开。
- 扩词后的实体形式按 **整词** 匹配（不会像普通长词那样自动加前缀 `*`）。

### 短拉丁词整词匹配（如 `ai`）

长度 ≤ 3 的纯拉丁短词（如 `AI` / `ai` / `US`）默认按 **整词** 搜索，**不会**自动变成前缀去误伤 `against`、`aid` 等。若确实要前缀，需显式写 `ai*`。

### 搜索时的排序：相关度 vs 时间

| 场景 | 默认排序 |
| --- | --- |
| 未搜索（浏览） | 按时间（最新 / 最旧，列表按钮切换） |
| 正在搜索 | 默认 **相关度**；可点排序按钮在「相关度 → 最新 → 最旧」间循环 |

新开一次搜索时会重新回到相关度优先。

## 2. 词云

侧边栏切到 **词云** 页签，可按日期范围查看近期高频实体与残余词。

### 点击行为

| 操作 | 效果 |
| --- | --- |
| **单击**词条 | 用该词 **替换**当前列表搜索并筛选文章 |
| **Shift+点击**（或 Cmd/Meta+点击） | **追加**到当前搜索（AND）；若该实体已在搜索里，再点一次会 **去掉** |

界面底部提示也写了：「点击搜索 · Shift+点击追加」。

### 颜色与大小（简要）

- **颜色**：按实体分组（人物、国家、地点、军事、政治、经济、灾害、组织、综合等）。图例可点选，过滤只看某一组。
- **大小 / 权重**：该时间窗内出现越多、越「热」通常越大（具体布局因平面 / 地球 / 树图模式而异）。

### 为什么有的大写、有的小写？

| 显示 | 常见原因 |
| --- | --- |
| **规范大小写**（如 `AI`、`Trump`） | 已在实体词典中，云上显示 **canonical（规范名）** |
| **小写残余**（如 `ai`） | 正文分词得到、但 **尚未** 建成实体；匹配不到词典时按残余词展示 |

把残余词提升成实体（例如 `ai` → `AI`）后，再回填索引，云上会显示规范名，且旧计数会合并。

### 如何维护实体词典

管理员：**设置 → 词云 → 实体词典**

1. **已有实体**：点「编辑」，改规范名、别名、分组后保存。
2. **残余词（词典里搜不到）**：用 **添加实体**，例如规范名 `AI`，别名可写 `人工智能` 等（大小写不同的形式常会自动保留为别名）。
3. 保存后：词云展示会尽量按新规范名解析；要让历史文章计数完全跟上，可到 **词条索引 → 立即回填**，直到待处理为 0。

词云实体别名同时服务：**词云展示匹配** 与 **侧边栏搜索的同义词展开**。

## 3. 兴趣标签 vs AI 标签

两种标签用途不同，不要混用「别名」概念。

| | **兴趣标签** | **AI 标签** |
| --- | --- | --- |
| 用途 | 你关心的「专题架」：封闭词表，文章入库后按标题/摘要匹配挂上 | 模型根据内容生成的自由标签，便于发现主题 |
| 从哪来 | 你在设置里维护词表（可启用自动匹配） | 启用 AI 打标后自动产生；可在设置里改名/删 |
| 侧边栏位置 | **订阅**页：兴趣标签列表（展示全部） | **标签**页：AI 标签列表 |

### 侧边栏怎么用

- **点击标签**：只看挂了该标签的文章。
- **计数**：常显示为 `总数 / 未读`（例如 `42 / 5`）。
- **兴趣标签排序**：可按名称（A–Z）或 **未读量** 排，方便先看积压多的专题。

### 设置里管理

**设置 → 标签管理**：

- **兴趣标签**：增删改词表；开关「启用兴趣标签匹配」；可选单篇上限。
- **兴趣标签别名（Aliases）**：把模型可能写出的同义词映射到规范兴趣标签，用于 **自动打标**，**不**影响全文搜索。
- **AI 标签**：浏览、重命名、改色、删除、清理无文章标签等。

### 两种「别名」对照（务必分清）

| 别名类型 | 在哪里配 | 影响什么 |
| --- | --- | --- |
| **词云实体别名** | 设置 → 词云 → 实体词典 | **搜索同义词展开** + 词云匹配 / 显示 |
| **兴趣标签别名**（`tag_aliases`） | 设置 → 标签管理 → 别名 | **仅自动打标** 挂兴趣标签，**不**扩搜索 |

## 4. 用好的实操建议

1. **为常搜的人 / 地 / 议题建双语实体**  
   规范名用你最常打的写法，别名补中英及其它常见变体（如 Trump / 特朗普，AI / 人工智能 / 人工智慧）。

2. **搜索时打规范名或任意别名均可**  
   不必刻意「中英都敲一遍」；同一实体多词会自动合并成一组 OR。

3. **不要用空格去 AND「同一实体的两个同义词」当两个条件**  
   例如 `Trump 特朗普` 会合并，结果仍是「这一人」。若你本意是两个不同概念，应使用两个 **不同实体**（或普通词）并用空格 AND。

4. **标签管「专题架」，实体管「全文里的名字变体」**  
   - 想固定跟「美联储 / 台海」这类书架 → 建兴趣标签（必要时配标签别名方便自动挂签）。  
   - 想搜正文里中英混写的人名地名 → 配词云实体，让搜索互相命中。

5. **短词误伤**  
   搜 `ai` 应命中整词 AI，而不是 `against`。若词云上仍是小写 `ai`，用「添加实体」升成 `AI` 并回填，显示与搜索体验会更一致。

6. **短语用引号**  
   政策名、固定搭配用 `"interest rate"`，避免被拆成两个独立 AND 词。

## 5. 例子（输入 → 含义 → 预期）

以下均指 **侧边栏 / 列表搜索**（严格 AND），并假定词典里已有相应实体（除非注明）。

### 1）`Trump`

- **含义**：命中 Trump 实体整组别名（含「特朗普」等）。
- **预期**：只写中文「特朗普」、未出现英文 Trump 的文章也会出现。

### 2）`Trump 特朗普`

- **含义**：两个词属于同一实体 → **合并为一组 OR**（chip 通常也只显示一个）。
- **预期**：不会因为「一文里必须同时有两种写法」而空结果；效果接近只搜 `Trump`。

### 3）`Trump china`

- **含义**：两个概念 → **AND**（Trump 组 **且** china 组）。
- **预期**：文章需同时覆盖两边话题；比单搜 `Trump` 更窄。

### 4）`人工智能`（已把该写法设为 AI 实体的别名）

- **含义**：扩成 AI 实体的 OR 组（如 `AI` OR `ai` OR `人工智能` …）。
- **预期**：正文只出现 `AI`、没有「人工智能」四字的文章也能命中。

### 5）`"interest rate"`

- **含义**：精确短语，相邻词按顺序匹配；**不做**同义词展开。
- **预期**：命中「interest rate」连写，而不是任意位置各出现一次 interest 与 rate。

### 6）`Trump OR Biden`

- **含义**：显式 OR。
- **预期**：谈 Trump **或** 谈 Biden 的文章都可进入结果（仍受其它条件约束）。

### 7）`ai` 整词（对比旧前缀误伤）

- **含义**：短拉丁词 / 实体扩词按 **整词** 匹配，不会自动变成 `ai*`。
- **预期**：匹配独立词 `ai` / `AI`，**不应**再靠前缀误命中 `against`、`aid` 等。若要前缀匹配，需显式输入 `ai*`。

### 补充：词云操作

| 操作 | 预期 |
| --- | --- |
| 单击「特朗普」 | 列表搜索变为该词（并享受实体扩词） |
| 已有 `Trump` 时再 Shift+点击「china」 | 搜索变为类似 `Trump china`（两组 AND） |
| 再次 Shift+点击同一实体词 | 从搜索中去掉该实体组 |
