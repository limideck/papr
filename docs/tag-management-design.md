# 标签管理体验重设计（v2）

> 目标：让「设置 → 标签管理」变成**直观、分级明确**的标签治理台。
> 现状问题：入口深藏在设置里、列表扁平、层级不可见、审核/屏蔽入口分散、操作靠右键菜单不直观、中英/近义重复难以发现。

## 1. 设计原则

1. **分级即结构**：树就是主视图（两级：主题 topic ⊃ 实体/子主题）。不做第三层，用“相关标签/别名”表达更细关系。
2. **一屏完成“看-选-操作”**：左侧树 + 右侧详情，选择决定可用操作；操作按钮始终可见、按所选对象启用。
3. **状态一眼可见**：未审核(新)、已屏蔽、有别名、低使用 都在节点上以徽标/底色呈现。
4. **批量优先**：治理多是批量动作（合并、改父、屏蔽、设类型）。
5. **防呆**：改名/合并前做冲突与环检测；删除/合并需确认并说明影响（多少文章会变）。

## 2. 信息架构与入口

- 新入口：**侧栏 Tags tab 头部加「管理」按钮** → 打开独立的 **标签管理页**（新路由 `/tags/manage`，浏览器可直达）；设置里保留原入口（旧路径兼容），内容与页面一致。
- 管理页三段式：
  - 顶部工具条：词表切换（**AI 标签 / 兴趣标签**）、搜索框（模糊找节点）、筛选（使用 ≥N / 仅未审核 / 仅已屏蔽 / 仅父级 / 仅无类型）、排序（字母/使用/更新）、批量模式开关。
  - 左栏：**树视图**（两级；父级可展开/收起，父级行显示 `子树文章数` 与 直接文章数）。
  - 右栏：**详情面板**（选中节点时）+ 底部/悬浮**操作台**。

## 3. 树视图（核心）

- 行结构：`[展开箭头] 名称 [类型icon 实体/主题] [使用数] [未审核•] [屏蔽×]`
- 行内快速动作（hover 出现）：查看该标签文章、+别名、屏蔽；右键/行尾 ⋯ 菜单含全部操作。
- 父级标题行可整体选中（点名称）或单独展开（点箭头）；两种语义都要一眼可分：箭头小、名称可点。
- 一次性/低频标签默认折叠区「长尾 (隐藏 >N 使用)」，一键只看高频。

## 4. 详情面板与操作（右栏）

选中单个标签显示：
- 基本信息：名称、kind、类型(entity/topic)、父级（显示可跳转）、直接/子树文章数、别名列表(可删/加)、创建/审核时间。
- 一句话建议（智能提示，本地规则即可）：如“与 X 表面相同”“与 Y 同实体（词表）”“是父级但只有 1 个子级”“未审核新词”“仅挂 2 篇文章”。

**操作台**（按语境启用）：
| 操作 | 说明 |
|---|---|
| 查看文章 | 跳到该标签/子树文章列表 |
| 改名 | 校验同层冲突；改名联动更新提示 |
| 合并到… | 输入/选择目标 → 显示影响（本标签 N 篇并入）+ 别名保留预览 → 确认 |
| 设为子级 | 选择父级（列出可选 topic；禁止成环/三层/自父） |
| 取消父级/设类型 | 一键 entity/topic/清除 |
| 加/删别名 | 别名建议来自词表与近义候选 |
| 屏蔽 / 恢复 | 屏蔽时选原因标签（重复/垃圾/不想看…），影响提示 |
| 标记已审 | 新词确认 |
| 删除 | 二次确认 + 影响数（仅低频/未被引用保护） |

**批量模式**：勾选多个（含跨父级）→ 操作台变批量：合并到…/统一设父/统一类型/批量屏蔽/批量删除。

## 5. 审核与屏蔽视图（与现有 v34 打通）

- 顶部筛选 `未审核/已屏蔽` 时，左栏树高亮相应节点并右上角给计数徽标；也可整表模式（现有 review/suppressed 列表保留，作为“队列视图”）。
- 队列视图每行：名称+父级+使用+示例文章标题2条；按钮：确认 / 屏蔽(原因) / 查看。
- 屏蔽列表可按原因过滤，恢复操作即时。

## 6. 视觉与实现约束

- 使用现有组件体系（react-query、虚拟列表、i18n）；树用可访问键盘（上下/左右展开、回车进详情）。
- 数据依赖（多为现状已有/即将有）：
  - `GET /api/tags` 每项含 parentId/tagType/usage/unread（v34 已加）；
  - 批量操作端点建议新增：`POST /api/tags/batch-merge`（body: fromIds[], targetId）、`POST /api/tags/batch-set-parent|type`、`POST /api/tags/{id}/alias`（已有）、屏蔽/审核（v34 已有）。
  - 命名建议：合并/设父/类型校验逻辑复用 core 已有函数（validate_tag_parent_link、merge_tags_keep_alias、carry_suppression）。
- 文案中英日三语；新流程全部带 help 提示与可撤性说明。

## 7. 分阶段实施（建议顺序）

- **P1 入口与框架**：路由 /tags/manage + 三段布局 + 左右联动（树↔详情）。
- **P2 树与节点操作**：展开/筛选/搜索 + 单节点全操作 + 详情面板。
- **P3 批量与审核**：批量模式 + review/suppressed 并入新视图（替换旧 Tab 区）。
- **P4 打磨**：别名建议、低频折叠、i18n、键盘可达性、空态/引导。

每阶段本地（含你 WIP 的 v34/树状改动）开发并可在 7411 演示预览；不发布，等你验收。
